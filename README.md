# A Stock Discipline Bot

轻量、Docker 可运行的 A 股持仓纪律监控，内置一个只在本机访问的台账页面。当前内置三只持仓的示例配置，并把“日内做 T”替换成可跨日、最长 10 个交易日的超短线卫星仓。

## 能做什么

- 北京时间开盘日 09:15、10:15、13:15、14:15 检查，15:30 汇总当天全部正式节点。
- 读取公开行情的日K、5分钟K、近似分时均价、历史同时间量能和同行/指数表现。
- 读取一手公开证据：上期所沪铜/沪金/沪银日行情、铜仓单与对应期权日终链，财政部/中债10年与30年国债收益率、工信部新能源车月度产销、电子信息制造业月报、卫星通信产业进展、上交所公司公告元数据与正向公司行动生命周期，以及上交所/深交所融资融券日终明细（按证券所在交易所路由）。深市公告使用深交所官网当前的 `annList` JSON POST（证券代码、公告频道和日期范围均按数组提交），不再使用已失效的旧 GET 参数。
- 独立生成 MA5/10/20、ATR14、RSI14、60日区间位置、动态支撑/压力和下一压力，再判断主仓风险与卫星仓。
- 主仓有效向下破位时优先降风险，并按中/高置信度分级减仓；普通破位须达到配置的深度或连续两根完整15分钟K位于支撑下方，单独放量不能升级为高置信度。10:15、13:15、14:15 都检查风险与加减仓，向下跳空和公司高风险公告有独立紧急例外。
- 主仓加仓必须同时通过突破持续/回踩、趋势、量能、同行/市场、产业与公告、下一压力空间及最低收益风险比；计划金额按账户净资产比例生成，再由含费用余量的可用现金、集中度、风险预算和ADV20成交容量限仓。
- 对接入时已经超配的亏损存量仓启用迁移模式：主仓只允许在接入风险天花板以内小幅回补；回到本轮固定成本线之上且同时出现过热/受阻时，将超配部分降至长期目标附近，普通反弹受阻则分批小幅减仓；确认减仓后单股与相关行业上限只降不升。卫星仓使用独立的限时覆盖额度，可临时高于主仓天花板，但不能绕过止损风险、行业上限、待处理减仓和冷静期纪律。
- 区分 `磨底候选`、`磨底确认`、`接近阶段顶部`、`阶段顶部确认`；猜底和猜顶都不会直接生成交易动作。
- 支持正式 `watchlist` 观察标的：空仓期间只等待首次建仓，不参与减仓、迁移或卫星仓逻辑；成交后手工切换为 `holding`。
- 卫星仓上限：江西铜业 300 股；新华保险、中国平安各 100 股。
- 操作通知仍只在明确动作时推送；15:30 日内总结无论是否触发动作都会发送一条飞书。
- 不连接券商、不自动下单；成交后必须手工更新 `config.yaml`，运行进程会在约15秒内热加载。
- 本地页面提供组合看板、已成交记录，以及可直接输入证券代码的智能股票池；不会提供券商连接或下单入口。

> 公开行情接口属于可替换的二级来源，不保证持续可用。程序会用时间戳门控并在数据缺失时静默，但不应被当作交易所级实时行情系统。本项目只提供规则化研究提醒，不构成投资建议。

## 启动

```bash
cp config.example.yaml config.yaml
cp .env.example .env
# 编辑 .env 中的 FEISHU_WEBHOOK；如机器人开启签名校验，再填 FEISHU_SECRET。
# 如需在新增股票时使用 DeepSeek 复核，再填写 LLM_API_KEY（非必需）。
docker compose up -d --build
docker compose logs -f monitor
```

生产环境部署和之后通过 ACR 更新的完整流程见
[`docs/deployment-alicloud-acr.md`](docs/deployment-alicloud-acr.md)。

首次启动后，在本机打开 `http://127.0.0.1:8787`。页面仅绑定本机回环地址，不会暴露到局域网或公网。首次会跳转到一个受密码保护的默认工作区；默认密码为 `960818`。工作区链接中的随机标识只用于定位和隔离这份组合，分享链接时也要一并通过安全方式分享对应密码。它包含四个页面：

- **看板**：只突出今天是否有动作、当前主仓/卫星仓和日内总结。
- **持仓**：只录入已实际成交的主仓、卫星仓交易和分红到账；页面会同步更新现金、股数和经济投入。
- **股票池**：只填证券代码即可读取公开公司资料，自动归类行业、同行、业务驱动、主要风险和证据路由；可选使用 LLM 在受限行业列表中复核。页面同时保留正式节点与15:30复盘。
- **消息配置**：每个工作区仅配置一个飞书 Webhook 和最低置信度；默认覆盖该工作区的全部持仓与观察仓。Webhook 会加密保存在本机。

只有已进入默认工作区后，右上角“新建工作区”才可用。新建会生成一份完全独立的组合：它有自己的持仓、观察仓、成交流水、资金、风险状态、复盘记录和飞书配置，不会继承默认工作区的账户数据或机器人地址，同时自动生成一条随机长访问密码。创建成功页只展示一次该密码，请立即保存；之后访问新工作区必须输入密码。新工作区先在“持仓”页校准当前可用资金，再通过“股票池”加入标的并录入已成交的首次建仓。

智能接入遵循“规则优先、模型可选、交易隔离”：公司身份与主营来自公开公司资料，行业归类先由确定性关键词和已支持证据路由完成。铜产业标的会同时建立“公司—商品暴露”档案，区分矿山、冶炼、加工和综合暴露，并确定性关联 CU 期货与 CU 期权。LLM 只在用户主动勾选时整理和复核研究档案，不能改写行业、商品或衍生品映射，也不能绕过技术、产业、公告、两融和风险门控。无法匹配现有产业证据的标的仍可加入并显示为“基础跟踪”，但在补齐行业证据路由前不触发首次建仓建议。

从这一版开始，`config.yaml` 仍保存策略、行业路由和风险约束；`portfolio.database_path` 指向的 SQLite 文件保存可变的账户事实、已确认成交与用户新增的观察标的。监控容器和页面共享它。已有 `config.yaml` 的首次启动会自动将其中的持仓与可用资金导入一次，不会覆盖随后通过页面录入的事实。

飞书自定义机器人 Webhook 与签名算法遵循飞书官方文档：`timestamp + "\\n" + secret` 作为 HMAC-SHA256 key，对空消息签名后 Base64 编码。

## 确认卫星仓成交

程序只会给建议，不会把建议视为成交。实际买入后，优先通过本机“持仓与成交”页面录入；也可在首次启动前在配置中初始化：

```yaml
main_shares: 1800          # 主仓不变
economic_basis: 99720.00  # 按完整交易周期净经济投入更新
satellite:
  active: true
  shares: 300
  entry_price: 40.00
  entry_date: 2026-07-28
  entry_support: 39.80
  target_price: 42.00
  stop_price: 39.35          # 使用建仓通知给出的固定风险退出价
```

卖出卫星仓后将 `active` 改回 `false`、`shares` 改为 `0`，并更新 `economic_basis`。不要把 `main_shares` 与卫星仓重复相加。

## 配置重点

- `economic_basis`：本周期累计买入及费用，减累计卖出净收入和现金分红，加相关税费后的净经济投入；用于后台 25% 风险限制。除息后务必下调本字段，或在 `corporate_events` 中登记分红并在除息前保持 `basis_adjusted: false`，由程序按有效成本计算风险。
- `portfolio.positions[].corporate_events`：现金分红事件。`record_date`（股权登记日）只延后普通迁移减仓和常规卫星止盈；有效向下破位、确认阶段顶部、硬风险、卫星止损/到期退出仍优先执行；`ex_date` + `cash_per_share` 用于除息后未调账时的有效成本校正。
- `evidence.cache_enabled`：当日首次成功的产业证据写入 `data/evidence_cache/`，避免盘中后段超时把已确认状态打回。
- `evidence.commodity_options`：商品期权辅助层。按公司商品暴露（铜/金/银）路由到上期所日终链；产业门控分别对应 `copper`/`gold`/`silver`。期权不替代期货门控，也不单独触发交易。铜暴露在铜产业门控通过后最多加一项确认；金、银同理。跨品种暴露（如铜金矿）只对当前行业门控对应的期权链加分，其余只观察。LLM 不能改行业路由，但公司资料或 LLM 研究描述里的金银铜关键词会进入暴露识别。
- `capital_flow`：东财主力净流入辅助层。持续净流出可否决新增；顶部减仓若资金仍净流入会降低置信度并标注背离。不单独触发买卖。
- `shareholder_count`：股东户数环比。下降=筹码集中（可计一项强确认），上升=分散（可作减仓弱确认）。季度低频，默认只辅助不单独交易。
- `stage_rules.overheat_*`：急涨过热提醒（ATR延伸+RSI），`OVERHEAT_WATCH` 本身仍为提醒级；只有迁移仓还同时满足固定成本线、显著超配等独立条件时，过热才可参与“回本降风险”判断。
- `strategic_rules.require_aligned_short_trend` / `minimum_ma20_slope_5d`：提高新增对趋势的要求；减仓与硬风险仍纪律优先，不等待趋势转弱。
- `position_sizing`：通用仓位模型。默认磨底确认首档 8%、趋势确认一档 6%、主仓常规目标 20%、卫星仓目标 3%、单股上限 30%，主仓新增的计划止损风险默认不超过账户资产 0.5%。卫星仓使用 `satellite_rules.entry_risk_weight` 的独立风险预算，默认0.25%。
- `migration_mode` 与 `portfolio.positions[].migration`：存量仓迁移模型。`initial_ceiling_weight` 固定接入时主仓天花板，`risk_principal_ceiling` 固定本轮最大风险本金；`recovery_trim_*` 控制超配仓回本降风险，成本锚点首次完整估值时冻结，也可用 `recovery_anchor_price` 显式校准，后续卖出不会降低该触发线。信号要求成本回收、显著超配以及过热/受阻同时成立；若放量突破且产业、公司证据同步增强则否决。计划股数按“长期目标+缓冲”计算，而非固定比例。每次确认主仓减仓后，天花板按“当前主仓权重+缓冲”向长期目标收缩且不得回升。`satellite_overlay_max_weight` 为卫星仓独立临时覆盖上限，默认3.5%；待处理减仓期间禁止卫星新增，确认减仓后默认再冷静一个完整交易日。
- `satellite_limit`：单轮卫星仓的安全股数上限，必须为 100 股整数；它不再决定计划规模。
- `main_adjustment_shares`：单次主仓新增的安全股数上限；主仓减仓改为按当前主仓比例计算，不受该上限影响。
- `portfolio.positions[].sizing`：可选的单股覆盖项；不配置时所有新股票自动继承全局比例模型。
- `portfolio.positions[].role`：`holding` 表示正式持仓，`watchlist` 表示尚未买入的观察标的。观察标的必须保持 `main_shares: 0`、`economic_basis: 0` 且无卫星仓。
- `watchlist_rules`：观察标的首次建仓节点、外部确认、最低目标空间和最低收益风险比。默认在10:15、13:15、14:15评估，其中13:15复用现有节点，不额外增加公开数据抓取次数。磨底确认完成时若价格已通过当前压力，必须由完整15分钟突破持续确认，再改用高于现价的下一有效压力；下一压力相对现价或ATR跨度异常时不参与建仓，并提示复核复权/历史尺度。
- `watchlist_entry_date`：观察标的首次成交并切换为 `holding` 时填写；默认经过3个完整交易日冷静期后，才允许继续主仓或卫星仓新增。
- `strategic_rules`：主仓突破/破位、破位最小深度/持续性、下一压力、最低收益风险比、加仓风险预算、分级减仓比例，以及主仓与卫星仓资本竞争时的小幅角色加分。普通高置信度破位至少需要两项外部同步走弱。
- `satellite_rules`：最长持有期、ATR自适应支撑距离/固定止损、反转或缩量企稳、最低目标空间和收益风险比。
- `stage_rules`：磨底/顶部状态阈值、顶部状态最长跟踪期、阶段顶部减仓比例，以及是否允许在严格条件下阶段性清仓。`top_rearm_new_high_ratio` 规定已确认成交一档顶部减仓后，价格须相对该次执行峰值创出至少指定幅度的新高，才会重新开启下一档普通顶部减仓。
- `risk.max_single_position_ratio`：按交易后仓位限制主仓与卫星仓新增集中度；`correlation_groups`同时限制保险等相关持仓。
- `correlation_groups`：同一标的若同时命中多个代码/行业分组，新增仓位按各组剩余空间的最小值约束，而不是按配置顺序取第一组。
- `holidays`：作为本地覆盖/应急兜底；启用 `trading_calendar` 后优先读取上交所官方年度休市安排并缓存，避免依赖手工维护单一年度表。快照、5分钟K、15分钟K和上一完整交易日日K分别做新鲜度检查。
- 共享台账会拒绝 NaN/Inf 价格、费用、分红和可用资金，避免非法数值污染现金、经济投入与风险计算。
- 容器迟到补跑仍会更新阶段状态，且 `scheduled_recovery` 节点会进入 15:30 日内总结。飞书发送采取节点级持久化 at-most-once claim；客户端超时视为不确定送达，不自动重发同一节点，避免“服务端已收、客户端超时”造成重复提醒。
- `notification.send_no_alert` 默认关闭；设为 true 时，无操作建议的节点也会发一条飞书观察消息。
- 未执行的风险/减仓建议首次触发立即通知；若次一交易日仍未确认成交，会发送一次“待处理提醒”，之后普通建议每2个交易日提醒一次，硬风险建议每日提醒；同一交易日只提醒一次，信号升级或解除后重新计算。
- `daily_summary.enabled/time`：控制开盘日的日内总结；默认 15:30，直接读取当天正式节点审计，不重新抓行情或重新判信号。
- `evidence`：产业与公告证据阈值。沪铜使用上期所主力合约多日结算趋势与铜仓单变化；沪金、沪银复用同一套期货趋势阈值，但不使用铜仓单；保险使用财政部/中债日终长端国债曲线；新能源车使用工信部月度产销同比；半导体要求集成电路产量和电子信息制造业增加值共同改善；中国卫星按航天通信/卫星应用处理，使用工信部卫星通信、卫星互联网许可及组网进展，不引用国防预算。上交所公告标题只做风险门控，经营类PDF仅在能提取明确同比数值时形成公司经营方向；`corporate_actions` 独立跟踪回购、增持、分红、员工持股和股权激励的提议—方案—实施—完成/终止状态。指数ETF不适用个股经营公告和公司行动门控，但产业证据仍必须通过。
- `margin_financing`：官方日终两融辅助层。余额快速去杠杆或极端拥挤时阻止新增；普通拥挤只降低机会排序，不会单独触发卖出。
- `execution_constraints` / `liquidity`：买入费用与现金余量，以及ADV20新增/常规迁移减仓容量。硬风险退出不受ADV门槛阻挡，但会在审计中给出分批容量和预计退出天数。

实际新增股数按 100 股向下取整，等价于：

```text
计划股数 = min(
  净资产比例对应股数,
  单股安全股数上限,
  可用现金对应股数,
  ADV20允许的新增容量,
  单股上限剩余空间对应股数,
  相关行业上限剩余空间对应股数,
  单笔风险预算 / (买入价 - 风险退出价)
)
```

## 观察标的与现有买入信号的区别

- `WATCH_ENTRY` 是首次建仓，不是主仓加仓，也不是卫星仓突击；只有10:15、13:15或14:15会评估。
- 只接受两类入口：磨底完成右侧确认，或完整15分钟放量突破并守住压力。普通“价格便宜”、磨底候选和盘中瞬时突破都不会通知。
- 首次建仓默认只占账户资产约5%，单笔计划风险不超过约0.35%；主仓磨底恢复/趋势加仓默认分别为8%/6%，卫星仓默认3%。所有计划仍受现金、单股/行业集中度、100股整数和安全股数上限约束。
- 观察标的最低目标空间默认5%、最低收益风险比2.0，高于普通主仓突破的4%和1.8；并要求产业与公告门控通过、同行与市场数据完整、至少两项强确认。
- 技术形态和外部证据均已通过、仅剩目标空间/收益风险比或一手风险预算未达标时，可发送一次当日“临界机会观察”提醒；该提醒明确标记为非买卖指令，不参与资本择优，也不计为操作信号。
- 观察标的没有“摊薄亏损”动机，因此处于阶段高位时直接放弃追涨；未触发时只进入15:30总结，不发送操作通知。
- 首次成交后必须填写真实 `main_shares`、`economic_basis`、`watchlist_entry_date` 并把 `role` 改为 `holding`；风险退出立即生效，继续新增则默认等待3个完整交易日。

当前可直接用于首次建仓门控的行业包括 `copper`、`gold`、`silver`、`insurance`、`insurance_financial_group`、`new_energy_vehicle`、`satellite_communications`、`semiconductor` 和 `optical_communications`。光通信门控采用工信部通信业运行月报中的业务总量、光缆线路长度和行业收入交叉确认。未知行业可以先以 `sector: generic` 加入观察，但由于没有产业证据路由，只会生成观察结论，不会发送首次建仓通知；补齐该行业的一手证据路由后才可启用建仓。

主仓已达到常规目标比例后不再自动加仓。迁移模式是例外，但主仓仅能使用接入天花板以内已经释放的额度：不会因为启用系统机械卖出，也不会把减仓后释放的全部空间一次补回。卫星仓不受20%主仓目标限制，也不占用主仓迁移额度；它最多在主仓天花板上方使用配置的临时覆盖额度。相关行业上限、20%风险预警、现金、独立止损风险预算、待处理减仓阻断和减仓后冷静期仍共同约束卫星仓。3%目标不足100股时，只有一手市值不超过配置的3.5%容差才会生成一手计划。单股确有不同波动或业务风险时可覆盖，例如：

## 证据如何影响建议

- 先做价格、支撑压力和量能判断，再读取持仓风险；产业与公告不参与技术位计算。
- 主仓加仓：产业证据必须新鲜且方向改善，公告查询必须成功且近期标题没有风险词；缺失、过期或冲突时不建议加仓。
- 卫星仓建仓：产业证据至少不能恶化，公告门控必须通过；卫星仓止损、到期退出和25%硬风险上限不因证据源故障而延迟。
- 主仓减仓：技术破位仍是主触发；产业、同行和市场明确走弱可作为外部确认。普通高置信度至少需要两项外部确认，放量只证明成交活跃度，不再单独把中置信度提升为高置信度。
- 两融与流动性：融资余额快速去杠杆可作为技术破位的辅助弱确认，极端拥挤/去杠杆会否决新增；两融永不单独产生信号。ADV20只限制新增和常规迁移减仓，不会阻挡固定卫星仓止损、到期退出或25%硬风险退出。
- 商品期权：只使用同到期、近 ATM、流动性达标的认购/认沽配对，读取 ATM Black-76 隐波及变化、25Δ 偏度、Put/Call 成交量与持仓量比、期限结构及价格—持仓同步性。它只能在对应商品期货门控已正向时最多补一项上行确认，或独立显示波动/下行对冲风险；不改写产业方向、不单独触发买入或卖出。单一合约权利金涨幅不等同商品期货或个股涨幅。
- 资本择优：同一节点出现多个新增机会时，主仓和卫星仓统一比较收益风险比、置信度、阶段位置及公司经营证据；主仓新增只有小幅角色加分，不会天然压过更优卫星仓。所有减风险动作始终排在新增前。
- 日终产业变量不是盘中实时信号；飞书中的“证据”行会明确数据日期。所有建议仍需人工复核和确认成交。

## 磨底和阶段顶部如何判断

- `磨底候选`：价格处于60日低位且近期出现过低RSI，只表示下跌可能进入钝化阶段，不建议据此抢反弹。
- `磨底确认`：还必须看到RSI回升、MA20跌势趋缓、完整15分钟收复支撑并站回近似分时均价，以及同行/市场与产业公告证据不再恶化。历史确认只在这三项右侧结构仍完整时才可短暂继承；一旦右侧反转消失，旧标签不能支持新的加仓。只有目标空间和收益风险比也达标，才会建议小幅恢复主仓。
- `接近阶段顶部`：价格靠近60日高位且RSI过热或相对MA20明显延伸。此时只停止追涨、收紧观察，不自动卖出；该状态、首次日期和阶段峰值会持久化，避免缓慢派发过程中因5日RSI窗口滚动而丢失上下文。
- `阶段顶部确认`：还必须出现RSI回落、跌回短均线、完整15分钟放量转弱并落到近似分时均价下方，且同行/市场或公司证据不再走强。默认分批降低主仓；通知只形成待执行档位，只有录入实际卖出后才推进档位。此后普通顶部减仓须先出现新的有效高点并再次确认，避免在同一轮派发中反复减仓。
- `阶段性清仓`：在顶部确认之外，还要求从阶段高位回撤达到配置阈值、跌破MA10，并出现公司经营指标恶化或交易所公告高风险事项。仅板块/市场转弱只能触发分批减仓，不能清空主仓。

每个节点的 `events.jsonl` 会保留 `stage`、逐项 `checks` 和 `metrics`，所以“为什么没有加/减仓”可以复盘到具体失败条件。15:30总结优先显示真正的约束项，例如日线趋势、突破持续性、产业证据、目标空间、收益风险比或仓位上限，不再用笼统的“确认不足”代替。

## 当前边界

- v1 默认使用腾讯公开行情的个股、同行代表股和宽基指数确认，不读取券商账户，也不自动交易。分钟接口没有可靠成交额字段，程序明确把分时均价标记为“5分钟收盘价加权近似值”，不冒充逐笔VWAP。
- 当前已结构化沪铜/沪金/沪银日行情、上期所铜仓单与沪铜/沪金/沪银期权日终链、长端利率、新能源车产销、集成电路产量与电子信息制造业增加值、卫星通信产业事件、交易所两融日终明细、公告标题元数据、回购/增持等正向公司行动生命周期，以及经营类公告PDF中可识别且能判断经济含义的同比数值。商品期权为可选官方日终辅助层，不是盘中实时期权系统；期权观察不构成建仓门控，金、银首次建仓仍以对应期货趋势为准。新能源车与半导体数据为月度滞后指标，卫星通信为事件/政策催化而非连续经营序列；这些证据只确认或否决建仓，不单独产生交易信号。TC/RC、LME全球库存、其他商品期权品种、NBV/价值率、偿付能力和资产质量尚未形成稳定一手结构化接口，重大事件及混合指标仍必须人工复核。
- 阶段状态是有时限、有重置条件的多指标状态机，不保证识别最低点或最高点；新增仓位依赖右侧确认，阶段清仓依赖反转与外部弱化，宁可错过一部分幅度，也不使用单一RSI或区间位置直接下结论。
- 普通公告标题不会被解释成正向证据；风险标题只会阻止新增风险，或在价格同步走弱时确认减风险。正向公司行动先由标题建立候选，再由交易所公告正文核验金额、用途和实施状态；提议、员工持股/激励仅记弱证据，正文不可用、行动终止或条款无法量化时不计正向确认。经核验的方案或实际实施最多增加一项外部确认及轻微机会排序分，不会单独触发买入，也不能覆盖产业转弱、技术/量能不成立、两融否决或风险上限。主仓和卫星仓新增仍须满足新鲜的5分钟/15分钟K、上一完整交易日日K、历史同时间量能及产业证据。
- 所有官方产业变量均为日终数据，不冒充盘中实时；公开来源不可用、过期或字段冲突时新增仓位建议自动静默。
- 法定休市日可维护在 `holidays`；即使漏填，盘中行情时间戳门控也会阻止用旧数据生成信号。
